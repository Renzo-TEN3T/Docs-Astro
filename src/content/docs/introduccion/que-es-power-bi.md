---
Power BI es una plataforma de análisis empresarial desarrollada por Microsoft que permite a los usuarios conectar, transformar y visualizar datos de múltiples fuentes.

## 🎯 ¿Para qué sirve?

Power BI te permite:

- **Conectar datos** de diferentes fuentes (Excel, SQL Server, web services, etc.)
- **Transformar y limpiar** datos automáticamente
- **Crear visualizaciones** interactivas y atractivas
- **Compartir dashboards** con tu equipo
- **Acceder desde cualquier dispositivo** (móvil, tablet, desktop)

## 🏗️ Componentes principales

### Power BI Desktop

- **Aplicación gratuita** para Windows
- Crear reportes y dashboards
- Modelado de datos avanzado
- Fórmulas DAX

### Power BI Service

- **Plataforma en la nube** (app.powerbi.com)
- Compartir y colaborar
- Actualización automática de datos
- Apps móviles

### Power BI Gateway

- **Conexión segura** entre datos on-premise y la nube
- Actualización automática
- Acceso a datos corporativos
